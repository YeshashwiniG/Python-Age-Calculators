# Age Calculator 🧮

A simple Python program that calculates a person's age based on their birth year and the current year. It then categorizes the person as a child, teenager, adult, or senior citizen.

## 📌 Features

* Takes the user's birth year as input.
* Takes the current year as input.
* Calculates the user's age.
* Categorizes the user based on their age:

  * **0–12:** Child
  * **13–19:** Teenager
  * **20–59:** Adult
  * **Above 60:** Senior Citizen
* Displays a personalized message based on the age category.
* Displays an error message for invalid age values.

## 🛠️ Technologies Used

* **Python**

## ▶️ How to Run

1. Make sure Python is installed on your system.
2. Clone this repository:

```bash
git clone https://github.com/YeshashwiniG/Python-Age-Calculators.git
```

3. Open the project folder.
4. Run the Python file:

```bash
python Age_Calculator.py
```

5. Enter your birth year and current year when prompted.
